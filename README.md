This is a music playlist you can shuffle through and add and remove songs via your files.

// You can search for a specific song in the playlist with the designated search bar.

This program was written in python.

I made this to learn how to subprocess. I chose this because I thought it would be good practice for
writing programs that make sounds. This proved to be a useful endeavour for my later game of Simon Says.

The GUI was made using pyFLTK, where nearly all components in the user interface are buttons or boxes.

I found some difficulty in ensuring there were no bugs when adding more music to the program, so anything
added would be sorted and reordered alphabetically.

If I could add some more details to this project to make it function better, I would add a search bar so you
can look up songs and play them from the bar.


How to run program:
Download the subprocesstest program

Download a few mp3 files (some are given in this repo)

Open the project using python3

Click the "add" button and parse through you folder to select some songs to add into the subprocessor.

Hotkeys are listen at the top of the window
